# Credit discipline — submission sprint

1. Local-first: HTML/CSS/JS edits, Playwright QA, screenshots, copy refinement, mock-data changes.
2. No repeated UX Pilot/Mobbin retries while the Android confirmation surface is broken.
3. Batch web research instead of many tiny searches; reuse already verified sources.
4. No image generation unless a visual is submission-critical and cannot be made with existing assets/CSS.
5. Keep AI Case Assist deterministic until a real API is intentionally wired.
6. Use one canonical prototype (`prototype.html`) and freeze milestone versions (`v1.2.html`, etc.).
7. Spend external credits only on: final deployment blockers, final public-source verification, or a high-value design audit once the MCP UI works.
